## 👋 About me

**최상혁 · Sanghyuk Roy Choi** — 중앙대학교 지능형반도체공학과 석·박사 통합과정 (2027.02 박사 학위 취득 예정)

기존 모델을 새로운 데이터에 적용할 때 생기는 문제를 분석하고, 필요하면 학습 구조나 데이터 처리 방식을 고치는 연구를 해 왔습니다. 최근에는 VLA 모델을 경량화해 6축 로봇 팔에서 검증했고, 휴머노이드 Unitree G1의 시각 기반 장애물 회피 보행 실험을 함께 수행했습니다.

- 🧊 **3D Vision** — 3D Gaussian Splatting, NeRF, 3D segmentation, CT/MRI
- 🔗 **Multimodal / Adaptation** — Transformer·attention, multi-omics, VLM/VLA, knowledge distillation
- 🤖 **Physical AI** — VLA 로봇 팔 조작(PiPER), 휴머노이드 보행·장애물 회피(Unitree G1)
